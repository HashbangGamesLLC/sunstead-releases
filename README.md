# Sunstead DIY downloads

Sunstead and its OS are free. Use your own Raspberry Pi 5 or buy parts from Amazon or any supplier. Prebuilt Sunstead systems with branded cases are optional.

- [DIY guide and free download](https://mysunstead.com/diy)
- [Raspberry Pi 5 community alpha](https://github.com/HashbangGamesLLC/sunstead-releases/releases/tag/v0.4.0-alpha.community.20261013.2)
- [Raspberry Pi Imager](https://www.raspberrypi.com/software/)
- [Optional prebuilt Sunstead](https://mysunstead.com/shop)

The current image is an alpha for Raspberry Pi 5 (64-bit). Physical first-boot testing is pending. Each release includes installation notes, SHA256 checksums and validation evidence. Choose the `.img.xz` for Raspberry Pi Imager; an application-update ZIP is not a card image.

Sunstead images include third-party operating system packages under their respective licenses. The image retains package copyright notices, and each release includes package versions and an OS SBOM.
